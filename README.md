# AYRA Android

A native Android AI assistant app. The Android application is built from this repository; the existing AYRA website is not modified.

## Build

Open the `android` directory in Android Studio, or use the GitHub Actions workflow to build a debug APK.

## Features planned

- Gemini-powered chat with configurable API key
- Urdu, Hindi and English interface options
- Speech input and spoken AI replies
- Chat history stored locally
- Camera integration and browser/search support
- AYRA voice activation (subject to Android background microphone restrictions)
- 3D avatar integration
